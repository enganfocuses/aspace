# Сборщики Speechcoach

Исходник редактора: speechcoach-api/admin/panel.src.html. Общая обработка правок: speechcoach-api/tools/additions-core.js. Собрать автономную страницу: node tools/build-panel.mjs, затем скопировать admin/panel.html сюда. issue-code.html синхронизируется из admin/issue-code.html.

Для изменения пересказов загрузите актуальный ZIP функции, откройте «Исправить записи» → «Сторителлинг · Пересказы (новая библиотека)». Можно менять русский и английский текст с абзацами, название, автора, год, ссылки и лицензию. ID существующей записи сохраняется. Для нового текста выберите библиотеку пересказов в сборщике и задайте уникальный ID.

Для картин доступны описание, биография, исторический контекст, современники и источники. Новую картину добавляйте через форму «Картины» с файлом JPG/PNG/WebP: сборщик преобразует изображение в JPG, выберет следующий номер и включит его в архив сайта. Для этого загрузите также полную основу сайта. Источники указывайте по строке: название | https://ссылка.

После добавления правок в пакет соберите ZIP функции и при новых картинах ZIP сайта. Загрузите их в Яндекс и на хостинг соответственно. Отправьте пакет в GitHub и слейте созданные PR, чтобы последующие сборки и Telegram получили те же изменения. Изменения хранятся в src/additions и применяются к библиотеке при сборке.

issue-code — выдача кодов и диагностика; ссылка на редактор материалов находится сверху. Секреты и настройки выдачи кодов не меняются.
