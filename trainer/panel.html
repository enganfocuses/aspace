📘 Как добавить темы и записи: пошаговая инструкция
  1. Основа. Ниже, в шаге 1, загрузите файл функции function-….zip, который сейчас работает в Яндексе. Если файла нет: GitHub → репозиторий enganfocuses/speechcoach-api → вкладка Actions → последний запуск «Проверка данных и сборка function.zip» (зелёная галочка) → внизу страницы раздел Artifacts → function-zip (скачивается архив; внутри будет function.zip, его и загрузите сюда).
  2. Что добавить. В шаге 2 выберите, в какой блок идут записи: «Темы» (режим «Темы», выбирается категория), «Дебаты», «Интервью», «Переговоры», «Конфликт» (реплики, выбирается сфера), «Литературно», «Речевые приёмы», «Артикуляция», «Дикция», а также все блоки сторителлинга: «Картины», «Отрывки для пересказа», «Словарный запас», «Простые слова», «Продолжи мысль», «Красивая речь» (цитаты и планы). Заполните поля и нажмите «Добавить в пакет». Так можно набрать много записей из разных блоков. Поправить или удалить уже имеющееся можно во вкладке «✏️ Исправить записи».
  3. Собрать. Шаг 3, «Проверить и собрать»: страница проверит записи (поровну по-русски и по-английски, нет повторов и пустых строк) и выдаст файлы. Если нашла ошибку, напишет какую и где.
  4. Яндекс (сайт и MAX). Нажмите «⬇ Функция для Яндекса». Откройте console.yandex.cloud → Cloud Functions → ваша функция → вкладка «Редактор» → способ «ZIP-архив» → выберите скачанный файл → «Сохранить изменения» (внизу). Подождите минуту и проверьте: …/d4e55siamfqcav7kct0l?p=ping должно показать версию. Переменные окружения трогать не нужно.
  5. GitHub (Telegram и резерв). Telegram-бот работает на Cloudflare и берёт данные из репозитория. Чтобы он тоже получил новое, нажмите в шаге 4 «📤 Отправить в GitHub» (нужен токен, инструкция там же): страница создаст Pull request. Откройте его по ссылке и нажмите зелёную кнопку «Merge pull request» → «Confirm merge». Через 1–2 минуты Cloudflare сам обновит бота. Вручную, без токена: GitHub → speechcoach-api → папка src/additions → Add file → Upload files → перетащите файл ….json из «Пакета для Claude» → Commit changes (создайте новую ветку и Pull request, затем Merge). Новые картины — в репозиторий enganfocuses/speechcoach, папка paintings, и затем новый архив сайта на хостинг.
  6. Проверка. Откройте бота и сайт, нажмите «Тема» в изменённом блоке. Если что-то не так, откройте issue-code.html → «Диагностика».
Важно: пока вы не загрузили функцию в Яндекс и не слили Pull request в GitHub, новые записи видны только на одной из сторон. Делайте оба шага.

Кнопка сама создаст в GitHub запрос на слияние (Pull request) с вашими добавками: файл с темами в закрытый репозиторий speechcoach-api и новые картины в репозиторий сайта speechcoach. Вам останется нажать «Merge» в GitHub: после этого Cloudflare обновит Telegram-бот сам.
Как получить токен (один раз)
  1. GitHub → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Название: «панель владельца». Срок: 90 дней.
  3. Repository access: Only select repositories → выберите speechcoach-api и speechcoach.
  4. Permissions → Repository permissions: Contents: Read and write и Pull requests: Read and write (больше ничего).
  5. Нажмите Generate token, скопируйте значение (оно показывается один раз) и вставьте сюда. Токен нельзя отправлять в чат; если он засветился, удалите его в GitHub и создайте новый.
Что куда: функцию загрузите в Яндекс (Cloud Functions → Редактор → архив → «Сохранить изменения», переменные не трогать). Сайт загрузите на хостинг, если добавляли картины. Пакет (запасной вариант) разложен по папкам репозиториев: speechcoach-api/src/additions/…json и speechcoach/paintings/…jpg. Основной путь: кнопка «Отправить в GitHub» ниже, ИИ для этого не нужен. ✨ Тексты в блоке «Больше режимов»

Пояснения, которые видны, когда на сайте нажимают «Больше режимов» и «Поддержать». Выберите текст, нажмите «Показать текущий текст», поправьте по-русски и по-английски. В тексте можно использовать кавычки «ёлочки» и знак ₽; переносы строки и угловые скобки нельзя.

📄 Документы сайта: оферта, политика, согласие

Как это работает. Документы лежат на сайте тремя файлами: offer.html (оферта), privacy.html (политика), consent.html (согласие). Здесь их можно поменять двумя способами:
А. Править текст по абзацам. Страница достаёт текущий документ из GitHub и показывает каждый абзац, пункт и ячейку таблицы в отдельном окошке. Меняете нужное, остальное не трогаете.
Б. Загрузить готовый файл целиком. Если вам прислали новую версию документа файлом .html (например, от юриста или от Claude), загрузите его.
Дальше в обоих случаях кнопка «Сохранить» делает две вещи: создаёт в GitHub запрос на слияние (Pull request), чтобы правка не потерялась, и собирает новый архив сайта для хостинга (на основе архива во вкладке «Сборщик», карточка «Основа»).
  1. Вставьте токен GitHub (тот же, что в «Сборщике»; хранится только в вашем браузере).
  2. Выберите документ и нажмите «Открыть документ» (способ А) или выберите файл (способ Б).
  3. Поправьте текст. Изменённые абзацы подсвечиваются. Не удаляйте знаки вида <a …>, <b>, <br>: это ссылки и выделение, их можно оставлять как есть.
  4. Не забудьте дату: кнопка «Поставить сегодняшнюю дату редакции» меняет «Редакция от …» в шапке документа.
  5. Нажмите «Сохранить: Pull request и архив сайта». Откройте Pull request в GitHub и нажмите «Merge pull request».
  6. Скачайте «Архив сайта с этим документом» и загрузите его на хостинг (так же, как обычный site-for-hosting.zip). Страница запомнит этот архив как новую основу.
  7. Откройте документ на сайте и проверьте, что изменения видны (в браузере нажмите Ctrl+F5).
Важно: перед следующей правкой всегда сливайте предыдущий Pull request. Если в тексте документа изменились цены, реквизиты или условия оплаты, поменяйте их и в боте/на сайте (раздел «Платные режимы»), иначе документ и программа разойдутся.
