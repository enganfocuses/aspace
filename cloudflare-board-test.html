Изолированный прототип для владельца: заметки сохраняются на этом планшете и в Cloudflare D1. Это ещё не полноценная совместная доска Aspace. Firebase используется только для входа.

Проверка входа…

Проверка новых версий автоматически каждые 15 секунд, пока вкладка открыта. Черновик на устройстве при этом не перезаписывается.

Ожидание авторизации.

Локальное сохранение после каждого изменения. При отсутствии сети изменения остаются только на этом устройстве. Отправка в Cloudflare — по кнопке.
