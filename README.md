# Aspace

## Настройка

1. В `config.js` укажите URL Firebase Realtime Database.
2. Для более стабильной видеосвязи, особенно при VPN и в корпоративных сетях, настройте TURN в `config.js`. STUN сам по себе не гарантирует соединение за NAT/VPN. Используйте TURN по UDP/TCP и желательно TLS на порту 443.
3. Для приватного пространства настройте Firebase Authentication и правила Realtime Database. Текущая версия клиентского приложения обращается к Firebase REST API без авторизации; ссылки режимов просмотра/редактирования ограничивают интерфейс, но сами по себе не являются защитой данных. Не используйте их как парольную защиту до настройки серверной авторизации и правил базы.

## Форматы экспорта доски

- SVG — векторное изображение, Miro поддерживает SVG как загружаемое изображение.
- PNG — растровое изображение для универсального импорта.
- CSV — текст и координаты объектов.

SVG/PNG импортируются как изображение; редактируемые объекты Aspace не превращаются автоматически в нативные объекты Miro.
