# Aspace

## Настройка

1. В `config.js` укажите URL Firebase Realtime Database.
2. Для более стабильной видеосвязи, особенно при VPN и в корпоративных сетях, настройте TURN в `config.js`. STUN сам по себе не гарантирует соединение за NAT/VPN. Используйте TURN по UDP/TCP и желательно TLS на порту 443. Не коммитьте постоянные TURN-пароли или неограниченные API-ключи в публичный репозиторий; предпочтительны короткоживущие credentials, выдаваемые сервером.
3. Для приватного пространства включите Firebase Authentication (email/password) и опубликуйте правила из `database.rules.json` в Firebase Realtime Database. Владелец получает доступ к `docs`, `img` и приватным `rooms`; гостевые ссылки используют случайный 192-битный токен в пути `/shares/{token}`. Для каждой доски создаётся одна постоянная ссылка с ролью `viewer` или `editor`; роль и отзыв ссылки управляются из списка досок. Ссылку можно переслать: любой, у кого есть URL, получит указанный в ней доступ. Не публикуйте её в открытых местах.

## Форматы экспорта доски

- SVG — векторное изображение, Miro поддерживает SVG как загружаемое изображение.
- PNG — растровое изображение для универсального импорта.
- CSV — текст и координаты объектов.

SVG/PNG импортируются как изображение; редактируемые объекты Aspace не превращаются автоматически в нативные объекты Miro.
