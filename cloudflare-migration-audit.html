Aspace · Готовность резервного Cloudflare

Безопасный аудит существующих досок Firebase. Не изменяет ни одной доски, медиафайла, публичной ссылки или правила доступа.

Проверка досок для резервирования

Проверяем вход владельца…

Программа считывает индекс досок и каждую доску только с правами владельца. Выявляет крупные документы и медиа, которые нужно учитывать при создании резервных копий в Cloudflare D1.

Ожидание входа.

Полная резервная копия содержит содержимое уроков и потенциально действующие токены доступа. Храни файл только в защищённом месте. Он не включает медиафайлы из отдельного раздела Firebase Storage/RTDB и не заменяет полную резервную копию Firebase.

Дальнейший порядок

Firebase остаётся основным хранилищем. Cloudflare будет резервом на случай сбоя. Прежде чем включить автоматическое переключение, настроим актуальное зеркало данных, очередь изменений и безопасную сверку версий при возвращении Firebase. Этот экран ничего не переключает.
