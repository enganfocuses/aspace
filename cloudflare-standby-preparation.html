Условия автоматического переключения

Автоматический резерв досок подключён к Aspace. Этот экран проверяет начальные копии. Для него нужны развёрнутый обновлённый Worker, постоянно актуализируемые версии досок, сверка изменений и корректный доступ учеников. Реальная синхронизация медиа и видеосигналинга — отдельные задачи.

Для запуска Worker Firebase-плагин в ChatGPT не нужен. В GitHub подготовлено ручное развёртывание с проверками и без изменений Firebase. Оно требует секреты Cloudflare в GitHub и готовую схему D1.
